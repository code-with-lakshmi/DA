Smart Classroom Attendance System

College Project

About Project

Full-stack web application to automate classroom attendance and OD management with secure authentication, geofencing, and role-based access control.

Problem Statement

Manual attendance tracking was time-consuming and prone to errors. Need for a secure, automated system with real-time monitoring.

Solution

Developed a web-based attendance system with facial recognition, QR code authentication, geofencing for location verification, and role-based access for faculty and students.

Technology Used

HTML CSS JavaScript Python SQL

Architecture

Three-tier architecture with frontend (React), backend (Python Flask), and database (MySQL). RESTful API for communication between layers.

Features

  • Facial recognition attendance
  • QR code authentication
  • Geofencing for location verification
  • Real-time dashboard for faculty
  • OD request management
  • Automated attendance reports

Impact

Reduced attendance tracking time by 80%, improved accuracy to 99%, and enabled real-time monitoring for faculty.

Future Scope

Integration with biometric systems, mobile app development, and AI-powered attendance prediction.

SparseMoney

Fintech Innovation

About Project

Smart micro-investment platform that rounds up transactions and invests spare change into customizable portfolios with analytics dashboards.

Problem Statement

Barriers to entry for investing, especially for young professionals and students with limited capital.

Solution

Created a micro-investment platform that automatically rounds up daily transactions and invests the spare change into diversified portfolios.

Technology Used

Python SQL Analytics Dashboard Finance

Architecture

Full-stack application with transaction integration, portfolio management engine, analytics dashboard, and investment API integration.

Features

  • Automatic round-up investments
  • Customizable portfolios
  • ETF, Gold, Index Fund options
  • Analytics dashboard
  • Portfolio tracking
  • Goal-based investing

Impact

Democratizes investing by making it accessible with small amounts, encouraging financial literacy and savings habits.

Future Scope

Integration with more investment options, AI-powered portfolio recommendations, and social investing features.
